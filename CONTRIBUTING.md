# Contributing

PRs welcome for docs a stranger can use, or for fixes to the notify script and the Exp6 require path.

- Open a PR against `master`. Keep the change small and say why.
- Do not commit webhooks, `.env`, `secrets/`, workbook data, or local box paths.
- Do not invent joy values or add fake CI badges.
- Do not copy private living-core hop0 / MCP runtime just to look complete.
- Do not add missing `ceo_*` act-children. They live in living-core.
- Joy is a ranked stock, not currency.
